Aithy is a local AI agent for real life.

Run a private agent with a real web UI, local inference, Grok subscription support, and Mesh sharing for the stronger machines in your home lab.

Aithy is pronounced ay-thee. It is named after my cat.

Use what you already have

Local, Grok, cloud, or family.

Aithy treats model choice as a runtime setting. Use local llama.cpp models, a normal provider key, an OpenAI-compatible endpoint, an eligible Grok subscription, or a family machine discovered through Mesh.

Home lab showcase

Your laptop can borrow the big machine.

Run Aithy on a GPU box, run Aithy on your laptop, pair them on the Mesh page, and mark both sides as family. The laptop can then select live validated services from the GPU box through a local OpenAI-compatible proxy.

API keys, Grok credentials, provider config, sessions, memories, and prompts are not advertised through discovery. Mesh shares catalogs and requests only after explicit pairing and mutual family trust.

Built for real agent work

Ax and Ax Agent give Aithy its spine.

Aithy is built on Ax, the TypeScript DSPy system for declaring typed signatures instead of hand-writing giant prompts. It uses Ax Agent, an RLM agent harness where the model can produce code or tool calls, a controlled JavaScript runtime executes them, and context policies keep long-running work stable without dragging every prior turn into the prompt.

That is the exciting part: Aithy is not asking one prompt to improvise everything. Typed inputs and outputs make model work checkable, runtime execution handles deterministic state and tool orchestration, and the agent loop can stay lean enough for local models, Grok subscriptions, cloud models, and Mesh-shared family machines.

The result is a real-world testbed for agent research: durable sessions, memory, dreams, skills, attentions, artifacts, local retrieval, sandbox permissions, and multiple supervised services all meeting in one inspectable product.

Ax: DSPy-style typed signatures, validation, streaming, providers, and optimization.

Ax Agent: RLM loop, secure JS runtime, context policies, functions, and child agents.

Runtime: web, queue-service, agent-worker, sandbox-worker, local-inference-worker.

Trust: local SQLite state, Bun secrets, permission prompts, sandboxing, pinned Mesh transport.

Inference: managed llama.cpp release, Qwen chat models, local embeddings, local reranking.

Quick start

Download a build. Or start from code.

Download a build

Grab the latest archive for macOS, Linux, or Windows from GitHub Releases. Unpack it, run the Aithy executable, then open the local web UI. 

gh release download --repo dosco/aithy --pattern 'aithy-*-darwin-arm64.tar.gz'
tar -xzf aithy-*-darwin-arm64.tar.gz
cd aithy-*-darwin-arm64
./aithy

Change the pattern for Intel Mac, Linux, or Windows. Windows uses aithy.exe. The UI listens on http://127.0.0.1:3000 by default.

github.com/dosco/aithy/releases/latest

Start from code

Use the source path if you want to hack on Aithy or follow the repo directly. You need Bun 1.3.14 or newer. 

git clone https://github.com/dosco/aithy.git
cd aithy
bun install
bun run start

Local state defaults to ~/.config/aithy/default/.

Aithy is local-first agent software built to be useful and hackable.
