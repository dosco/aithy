A local AI lab for modern agents.

Aithy is a local-first platform for experimenting with the latest agent research, running private AI workflows, and routing work across your laptop, APIs, and home GPUs.

Model router

Bring the model stack you actually use.

Aithy treats model choice as runtime configuration, not a rewrite. Use a small local model for private work, a stronger API model for heavy reasoning, an eligible Grok subscription for chat and web.search, or a LAN machine with more GPU through Mesh.

Home lab Mesh

Your laptop can borrow the big machine.

Run Aithy where you work, run Aithy on the GPU box, pair them on the Mesh page, and mark both sides as family. Your laptop can then select live validated inference or search services through a local OpenAI-compatible proxy.

Discovery does not advertise API keys, Grok credentials, provider URLs, prompts, sessions, memories, model lists, or service catalogs. Catalogs and requests move only after explicit pairing and mutual family trust.

Agent engineering

Ax and Ax Agent are the engine under the shell.

Aithy is built on Ax, the TypeScript DSPy system for typed signatures, validation, streaming, providers, and optimization. Instead of one giant improvised prompt, Aithy can describe model work as structured inputs and outputs that are easier to check, route, and run across different providers.

The agent loop uses Ax Agent, an RLM-style harness where the model can produce code or tool calls, a controlled JavaScript runtime executes deterministic work, and context policy keeps long sessions useful without loading every old turn into every new prompt.

That architecture is why Aithy can be flexible without turning into a pile of ad hoc tool prompts: local models can handle narrow work, larger hosted models can take harder turns, and the runtime keeps memory, retrieval, permissions, artifacts, and services inspectable.

Quick start

Download a build or run from source.

release install

Download a build

Grab the latest archive from GitHub Releases, unpack it, run the Aithy executable, then open the local browser control surface. 

gh release download --repo dosco/aithy --pattern 'aithy-*-darwin-arm64.tar.gz'
tar -xzf aithy-*-darwin-arm64.tar.gz
cd aithy-*-darwin-arm64
./aithy

Change the pattern for Linux or Apple Silicon macOS. The local UI listens on http://127.0.0.1:3000 by default.

github.com/dosco/aithy/releases/latest
source install

Start from code

Use the source path if you want to hack on the runtime, follow the repo directly, or inspect the whole stack while it runs. You need Bun 1.3.14 or newer. 

git clone https://github.com/dosco/aithy.git
cd aithy
bun install
bun run start

Local state defaults to ~/.config/aithy/default/.
